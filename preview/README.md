# Первый временный тест русского перевода

Поддерживается только XGIMI Z9X HB dapengfhm, Android 13, прошивка 6.17.12, с точным совпадением исходного APK и локального кандидата из session.json. На Windows пользователя сборка уже завершилась: исходный SHA-256 69e51d6087f1554153ae9d23008a77aec10747476a8adb206ab2c0cc816fa411; кандидат a3371e5bbec22e0ac154f96060ebe11a296daeebc9b96f0c5f68f03193c142fb. Полный APK остался у пользователя, в GitHub не загружался. Root probe подтвердил uid=0 в xgimi_ssh и восстановление пустого params.

## Запуск

Распаковать preview-kit в z9x-hb-preview рядом с z9x-hb-build в папке platform-tools. Запустить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-preview\run-preview.ps1
```

По умолчанию выбирается последний успешно подготовленный preview-* с session.json внутри z9x-hb-build. Скрипт выводит USING_SESSION. Можно явно указать `-SessionPath` с нужным каталогом. Фактический APK проектора, локальный оригинал и кандидат ещё раз сверяются по SHA-256 перед передачей. Выйдите на главный экран; сценарий также отправляет обычное нажатие HOME перед обновлением процесса настроек.

Сначала выполняется проверка bind-mount и unmount на двух собственных временных файлах с таким же SELinux-типом. Настройки проектора на этом этапе не подменяются. При недоступности этих операций тест завершается до замены APK. Затем сохраняется полный текущий APK на устройстве, останавливается только сервис обслуживания Amnesia, ожидается завершение уже выполняющегося native maintenance. Системный APK подменяется одним bind-mount; запись в system/vendor, прошивка, очистка данных и изменение HOME не выполняются.

Настройки перезапускаются способом для этого варианта HB: force-stop только com.android.newsettings и запуск lifecycle provider. Подмена считается загруженной только после трёх последовательных проверок фактического inode APK в maps процесса настроек. Binder-команды ограничены по времени; отсутствие timeout приводит к отказу до подмены.

После APPLIED_5_MINUTES откройте настройки пультом и проверьте тексты. Автооткат через 300 секунд после подтверждённой загрузки возвращает прежний видимый APK, перезапускает настройки и восстанавливает ранее работавший сервис обслуживания Amnesia. Отдельное закрепление после включения питания не выполняется. Во время этих пяти минут не запускайте root-probe и не перезапускайте SSH-службу: тестовый процесс работает в ней. Отключение ADB само по себе не завершает процесс vendor-службы; отключение/перезапуск самой службы может прервать его.

## Досрочный откат

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-preview\run-preview.ps1 -Rollback
```

Используется последний локальный runtime.json. Для конкретного теста задайте тот же -SessionPath. Запрос идёт через обычный контрольный файл в принадлежащем shell каталоге. При подтверждённом ROLLED_BACK очищаются старые параметры работающего SSH-клиента перезапуском службы с исходным пустым params.

Откат проверяет собственный mount ID и уникальный inode перед unmount. При чужом изменении отказывается снимать чужую подмену; восстановление собственного изменения сервиса обслуживания всё равно выполняется. Все отказные состояния выводятся отдельно и не объявляются успешным откатом. Временные файлы/снимок сохраняются для диагностики. Если процесс теста принудительно уничтожен, наблюдатель не сможет выполнить откат; bind-mount не переживает перезагрузку, а init-конфигурация и ключи этим тестом не меняются.

## Границы проверок

Проверены синтаксис shell, исполнение PowerShell-драйвера на PowerShell 7.4.6/Linux с подставным ADB (включая Unicode-пути, выбор сессии, отказ для изменённого кандидата и запрос отката), пять модельных сценариев владения mount/отката. Это не испытание Android, SELinux, mount propagation или нового APK на проекторе. Коды и журнал проверок приложены. Сам runtime preview на проекторе ещё не запускался; это первый аппаратный тест, а не готовая постоянная установка.

Диагностика выводит только фазу, пути временного теста и журнал своих операций. SSH-ключи и их содержимое не читаются и не изменяются. Права UID=0 используются только для указанного временного теста.
