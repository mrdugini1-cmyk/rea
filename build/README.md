# XGIMI Z9X HB 6.17.12 — подготовка временного теста

Root probe на устройстве подтвердил uid=0 и восстановление исходного params. Этот комплект выполняет только подготовку на компьютере: сохраняет полный текущий APK через adb pull, проверяет его части по SHA-256, собирает полный unsigned-кандидат с переводом, сохраняет все остальные файлы и выравнивает несжатые ZIP-записи на 4 байта. resources.arsc остаётся несжатым. Исходный APK не перезаписывается. На проекторе ничего не устанавливается.

Нужны только штатный Windows PowerShell и существующий adb.exe. Из папки platform-tools запустить:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-build\prepare-preview.ps1
```

При нескольких подключённых устройствах добавьте `-Serial` с нужным ADB serial. Результат — новый каталог preview-... внутри комплекта: before.apk, candidate.UNSIGNED.apk, session.json. Это материалы для временного теста, не обычное обновление; adb install не используется. До подготовки отдельного сценария теста не подменяйте системные файлы вручную.

Сборщик исполнен на PowerShell 7.4.6 в Linux на искусственном архиве из всех присланных частей с контрольными assets/native-файлами. Проверены 1751 entry, 601 несжатая запись с выравниванием, hashes всего содержимого, отказ для другой версии и существующего выхода. Запуск Windows PowerShell 5.1 в этой среде недоступен; используется синтаксис и API, совместимые с ним. Полный реальный APK собирается на вашем компьютере и сверяется там.
