# XGIMI Z9X HB: перевод v3 и постоянное подключение

Только для XGIMI/Product_dapengfhm/goat_elegant:13/TP1A.220624.021.A1/v6.17.12:user/dev-keys. Исходный полный APK: SHA-256 69e51d6087f1554153ae9d23008a77aec10747476a8adb206ab2c0cc816fa411. Предыдущую пробную сборку пользователь подтвердил фотографиями. Новая v3 и автозапуск после перезагрузки ещё требуют проверки на устройстве.

Меню: «Проекция», «Изображение», «Сеть», «Источник», «Bluetooth», «Звук», «Общие». Суффикс HDMI «设置» заменён на «— настройки». Остальной перевод v2 сохранён. PackageInstaller — отдельное приложение; его окно установки этот пакет не переводит.

## Сборка на Windows

Распаковать в z9x-hb-final рядом с adb.exe. Выполнять из platform-tools:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-final\prepare-final.ps1
```

Скрипт берёт полный before.apk из сохранённой папки z9x-hb-build/preview-*, проверяет его полный SHA-256 и все заменяемые части, собирает полный выровненный APK в новой папке final-*. Ничего на проекторе не меняет. Полный APK содержит штатные assets и native-библиотеки из резервной копии. Он неподписанный: не применять через adb install и не записывать поверх APK в системном разделе.

## Установка без таймера

Дождаться отката предыдущего пятиминутного теста. Затем:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-final\install-persistent.ps1
```

Должен появиться PERSISTENT_ACTIVE. Установщик проверяет точную прошивку, исходный APK, пустые исходные SSH params, сохраняет локальную квитанцию persistent.json. Существующую попытку не перезаписывает. Восстанавливает доступ к папке перезапуском штатной службы, которая сама устанавливает её права. Подмена APK выполняется bind mount из /data, без записи в EROFS, без сброса настроек и без изменения SSH-ключей.

Для повторного подключения после запуска используется существующая служба xgimi_ssh: её params содержит ProxyCommand, запускающий фиксированный root-owned скрипт из /data/z9x-ru-persistent. Исходные params сохраняются для удаления. Скрипт ждёт завершения загрузки и исходного перевода Amnesia, проверяет файлы, подключает APK и перезапускает только процесс настроек. Служба обслуживания Amnesia останавливается на время подмены и затем запускается обратно; до PERSISTENT_ACTIVE проверяется сохранение нашего монтирования в течение 45 секунд. Постоянный worker работает без пяти- и десятиминутного таймера.

Автозапуск зависит от запуска штатной службы xgimi_ssh при включённом xgimi.remoteDebug.on. Неподтверждённую конфигурацию после перезагрузки нельзя считать проверенной постоянной установкой. При другом исходном APK или конфликтующем монтировании worker отказывается от подмены и сохраняет журнал. Не меняет лицензирование Amnesia и не отключает её компоненты.

## Проверка после перезагрузки

После успешного PERSISTENT_ACTIVE перезагрузить проектор. Дождаться ADB и появления меню; на применение может уйти несколько минут. Затем:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-final\verify-persistent.ps1
```

BOOT_PERSISTENCE_VERIFIED означает: загрузка действительно новая, worker активен в этой загрузке, SHA-256 видимого APK совпадает с новой сборкой. Приложить вывод, если проверки не прошли. Журнал:

```powershell
.\adb.exe shell cat /data/z9x-ru-persistent/phase
.\adb.exe shell tail -n 100 /data/z9x-ru-persistent/session.log
```

## Удаление

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\z9x-hb-final\install-persistent.ps1 -Rollback
```

Запрашивает остановку worker, снимает только собственное монтирование, восстанавливает исходные SSH params, проверяет исходный APK и параметры, затем очищает запрос перезапуском службы. При чужом монтировании отказывается снимать его. Файлы восстановления остаются. Не удалять локальную папку final-* и persistent.json до подтверждения отката. Повторную установку поверх оставшейся папки восстановления скрипт намеренно не выполняет.
