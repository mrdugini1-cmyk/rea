# XGIMI Z9X HB — русский перевод v2

Подготовлены 262 перевода китайских ресурсов, редактура 924 строк, 18 надписей в экранах и 147 строк в DEX. Это отдельные слои правок; их числа не означают количество уникальных строк. Таблицы изменений и результаты статических проверок находятся рядом.

На устройстве с прошивкой dapengfhm 6.17.12 временный root probe подтвердил `uid=0(root)`, контекст `u:r:xgimi_ssh:s0` и восстановление исходного пустого params. Привилегированное исполнение проверено, установка перевода и постоянное закрепление ещё не выполнены.

Следующий шаг — скачать **[z9x-hb-build-kit.zip](z9x-hb-build-kit.zip)**, распаковать и запустить `prepare-preview.ps1` из папки platform-tools. Он сохраняет полный текущий APK, сверяет исходные части, собирает полный unsigned-кандидат с выравниванием ресурсов и сохраняет SHA-256. Это только подготовка на компьютере, без установки. Инструкции: [build/README.md](build/README.md).

`adb install` для unsigned-кандидата не используется. Первое применение готовится как временный тест с откатом, без записи в системный раздел и без автозапуска. До проверки результата на экране готовой установленной русификации не заявляется.
