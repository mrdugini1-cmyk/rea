## Первый тест

После подготовки через [build-kit](z9x-hb-build-kit.zip) скачать **[preview-kit](z9x-hb-preview-kit.zip)** и распаковать в z9x-hb-preview в папке platform-tools, рядом с z9x-hb-build. Запустить `run-preview.ps1`. Выбирается последний подготовленный preview-*; все исходные hashes проверяются повторно.

Это первый аппаратный тест нового APK, на 5 минут, с запросом досрочного отката. Постоянная установка ещё не выполнена. Инструкции и границы проверки: **[preview/README.md](preview/README.md)**. Перед APK проверяются bind/unmount на частных временных файлах. При применении временно останавливается только сервис обслуживания Amnesia; при откате его предыдущее состояние восстанавливается. В системный раздел файлы не записываются.

Unsigned-кандидат не устанавливать через adb install. Для досрочного отката запустить тот же `run-preview.ps1 -Rollback`. Во время пяти минут не перезапускать службу SSH и root-probe: в ней работает тестовый процесс.
