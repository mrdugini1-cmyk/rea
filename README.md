## Первый тест

После подготовки через [build-kit](z9x-hb-build-kit.zip) скачать **[preview-kit](z9x-hb-preview-kit.zip)** и распаковать в z9x-hb-preview в папке platform-tools, рядом с z9x-hb-build. Запустить `run-preview.ps1`. Выбирается последний подготовленный preview-*; все исходные hashes проверяются повторно.

Это первый аппаратный тест нового APK, на 5 минут, с запросом досрочного отката. Постоянная установка ещё не выполнена. Инструкции и границы проверки: **[preview/README.md](preview/README.md)**. Перед APK проверяются bind/unmount на частных временных файлах. При применении временно останавливается только сервис обслуживания Amnesia; при откате его предыдущее состояние восстанавливается. В системный раздел файлы не записываются.

Unsigned-кандидат не устанавливать через adb install. Для досрочного отката запустить тот же `run-preview.ps1 -Rollback`. Во время пяти минут не перезапускать службу SSH и root-probe: в ней работает тестовый процесс.

[Подробный отчёт о переводе](translation-report.md) · [Примеры редакторских исправлений](examples.ru.tsv) · [Состояние](status.json). Статические и модельные проверки приложены отдельно; они не заменяют проверку интерфейса и отката на проекторе.

## Текущее состояние первого запуска

Root preflight остановил попытку до APK-подмены из-за несовпадающего видимого хеша. ADB подтверждает исходные 69e51d60…; причина root-расхождения ещё проверяется. Следующий шаг — обновить preview-kit и выполнить `run-preview.ps1 -Diagnose`, оставив настройки открытыми на проекторе. Этот режим не применяет перевод, сохраняет проверки хешей и собирает данные для исправления области видимости файловой системы. Кандидат повторно собирать не требуется.

## Исправление hash в Android shell

Причина остановки подтверждена: алиас mksh `hash` перекрывал функцию сценария. Прямые хеши во всех проверенных пространствах совпадают с исходным APK. Helper переименован в `z9x_file_sha256`; проверки SHA сохранены. Ошибка воспроизведена и исправление проверено в mksh; модельные проверки отката повторены в sh и mksh. Следующий шаг — обновить preview-kit и запустить обычный `run-preview.ps1` без `-Diagnose`. Пересборка APK не нужна.


Исправление остановки preview на Android 13

Подтверждено выводом устройства: worker завершался с кодом 255 сразу после «Service stopped». В AOSP Android 13 runStopService возвращает -1 даже при успешной остановке. Теперь код команды журналируется, а решение принимается по фактическому состоянию службы через dumpsys; неизвестное состояние по-прежнему блокирует подмену APK. Чтение mount ID выполняется встроенным read в процессе оболочки, поскольку mksh закрывает fd 8 при запуске внешнего awk.

Повторный запуск разрешён после подтверждённого ROLLED_BACK и завершения worker, с проверкой восстановления SSH params. Проверки исходного и нового APK сохраняются. Предыдущая квитанция сохраняется. Полный APK пересобирать не нужно. Успешное применение на проекторе ещё не подтверждено.
